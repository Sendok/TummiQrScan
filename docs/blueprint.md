# **App Name**: ScanVerse

## Core Features:

- QR Scanner: Enable QR code scanning using the device camera with real-time result display. Save the scan result with a timestamp and optional location data to Firestore.
- Scan History: Display a filterable list of scan history from Firestore. Include options to copy the scanned value to the clipboard or open it in a browser.
- Notes and Labels: Allow users to add notes or labels to each scanned QR code and store them in Firestore.
- AdMob Integration: Show banner ads on the scan history and result pages to monetize the app. Consider rewarded ads for unlocking premium features.

## Style Guidelines:

- Primary color: Navy blue (#000080) to create a sense of trust and reliability.
- Background color: Forest green (#228B22) for a clean and unobtrusive backdrop.
- Accent color: Yellow (#FFDA63) to provide visual interest and highlight important interactive elements.
- Headline font: 'Space Grotesk' (sans-serif) for a techy and modern feel; body font: 'Inter' (sans-serif) for readability.
- Use simple, modern icons to represent different functions and categories, with a consistent style.
- Employ a clean, card-based layout for displaying scan history and details. Prioritize content and readability.
- Subtle animations for transitions and feedback, like a scan line effect during QR scanning or a smooth slide-in for the scan history.
